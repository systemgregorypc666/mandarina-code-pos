🍊 Mandarina Code POS

Mandarina Code POS es un sistema de escritorio para el Control de Inventario y Punto de Venta (POS) rápido, seguro y robusto. Diseñado para optimizar los procesos de facturación, administración de productos y control de caja en establecimientos comerciales y tiendas minoristas.

🚀 Características Principales

  • Ventas y Facturación Ágil: Módulo de caja optimizado para registro de ventas rápido.
  • Soporte para Hardware Comercial: Compatibilidad nativa con lectores de código de barras e impresoras térmicas de tickets (58mm / 80mm).
  • Gestión de Inventario y Stock: Control de productos, categorías, entradas, salidas y ajuste automático de existencias.
  • Control de Anulaciones y Devoluciones: Gestión segura de reversión de transacciones con auditoría.
  • Seguridad y Usuarios: Sistema de inicio de sesión (FormLogin) con control de permisos y roles para cajeros y administradores.
  • Módulo de Licenciamiento: Sistema integrado de validación de licencias anuales mediante claves alfanuméricas.

🛠️ Tecnologías Utilizadas

  • Lenguaje: Visual Basic .NET (.NET Framework)
  • Base de Datos: SQLite (Base de datos local rápida e indestructible)
  • IDE: Microsoft Visual Studio
  • Plataforma Objetivo: Windows (Desktop)

📂 Instalación y Despliegue

  1. Descarga el paquete compilado en la sección de Releases o compila la solución desde Visual Studio en modo Release.
  2. Ejecute el archivo ejecutable MandarinaCodePOS.exe.
  3. Inicie sesión con las credenciales asignadas por el administrador.
  4. Para la activación de la licencia del sistema, ingrese la clave alfanumérica en la pantalla de Acerca De.
