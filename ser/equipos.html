📋 Lista de Equipos Recomendados para Mandarina Code POS1. Lectores de Código de Barras ("Pistolas")Para el punto de venta (PC Windows) y para las ventas móviles, lo ideal es recomendar modelos estándar que no requieran drivers complejos (Plug & Play por USB o Bluetooth/HID):Opción Económica y Robusta (Punto Fijo - USB):Modelos: Lectores láser estándar USB de 1D (ej. marcas tipo Netum, Eyoyo, Honeywell Voyaguer o genéricos chinos tipo USB Barcode Scanner). Ventaja: Conectar al puerto USB y listo. En Windows actúan automáticamente como un teclado, enviando el código leído directo al campo de búsqueda de FormVentas.vb.Opción Inalámbrica (Híbrida para PC y Celular/Android):Modelos: Lector de código de barras Bluetooth / 2.4G Inalámbrico (1D/2D para códigos QR y barras).Ventaja: Le sirve tanto para la computadora en la tienda como para la App móvil en la calle conectándolo por Bluetooth. 2. Impresoras de Recibos / Tickets TérmicosLas impresoras térmicas son la mejor opción porque no usan tinta (usan papel térmico económico) y son ultrarrápidas:Impresora de Escritorio (Para la Tienda / Oficina - USB / POS-58 o POS-80):Formato: Impresora Térmica de 58 mm o 80 mm (Conexión USB / Serial / LAN).Modelos comunes: POS-58MM, Epson TM-T20, Xprinter XP-58 / XP-N160I.Ventaja: Se conecta por USB al equipo Windows, se configura como impresora predeterminada y Mandarina Code POS imprime el recibo/factura al instante.Impresora Portátil de Bolsillo (Para Vendedores en Calle - Bluetooth):Formato: Mini Impresora Térmica Portátil de 58 mm (Batería recargable y conexión Bluetooth). Modelos comunes: GOOJPRT PT-210, POS-5802DD, MTP-II.Ventaja: Muy ligera, se lleva en el cinturón o bolso y permite imprimir el ticket directamente desde el teléfono Android.3.
